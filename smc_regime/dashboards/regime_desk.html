Tracking universe

Methodology. Every trade is tagged with the regime (choppy / trending / parabolic, split up / down / flat) active on its own entry date, not the ticker's current regime. Ranking metric is average return per trade; entries below 15 trades are marked thin and excluded from the headline pick. Long-only, single-position backtest — no shorting, no pyramiding.

The vol-sized drawdown. The muted second figure is the same trades at a volatility-targeted stake: each position scaled to min(1, 20% ÷ trailing 60-bar volatility), capped so it can only ever shrink a position, never lever one up. Same entries, same exits, same win rate — only the size of the bet changes, which is why the pair is a like-for-like comparison and not two different backtests. It is shown beside the full-size figure rather than replacing it because only the full-size number is comparable with earlier runs and with the snapshot log. Win rate, average return and worst trade carry no sized twin: a weight cannot move them. The motivation is that this strategy set’s drawdown is a stake problem rather than a signal one — bucketing rsi_dip_recovery’s trades by volatility at entry, the loss rate is flat across quintiles and losing trades sit ~420 days in every bucket, but the average loss runs −10.6% on the calmest fifth against −38.1% on the wildest. A blank means the run recorded no sizing, or sizing made no difference to that bucket.
